# Descargas públicas del clima (DataLab Ec)

Robots que solo bajan datos de fuentes públicas (mareógrafos IOC, boyas TAO/Argo, OISST, SYNOP, índices de El Niño
de NOAA/BoM). Corren aquí porque en repositorios públicos GitHub Actions no cobra minutos. Los resultados se guardan
en la rama `datos-clima` (carpeta `registro/`), de donde los toma el sistema del clima.
